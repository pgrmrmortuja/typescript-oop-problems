# TypeScript & OOP

## Overview

This repository contains my TypeScript and Object-Oriented Programming knowledge. The main goal is to practice TypeScript fundamentals, type safety, generics, interfaces, and object-oriented programming concepts through practical coding problems.

## Problem Solving

This repository includes 8 TypeScript problems covering the following topics:

1. Function Parameters and Default Values
2. Union Types and Type Narrowing
3. Tuples and Readonly Modifiers
4. Generics and Rest Parameters
5. Interfaces and Array Filtering
6. Generics with `keyof` and `typeof`
7. Classes, Inheritance, Encapsulation, and Access Modifiers
8. Promises and Asynchronous Functions

All solutions are implemented in the `solutions.ts` file.
